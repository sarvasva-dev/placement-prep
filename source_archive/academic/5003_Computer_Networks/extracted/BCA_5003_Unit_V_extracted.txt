1. Unit-V Roadmap
Unit V joins Transport Layer functions with upper OSI layers—Session, Presentation, and Application—and includes networking
services such as email, file transfer, remote access, routing, and security. It is a high-scoring unit because questions are
definition-plus-diagram based and PYQs repeat frequently.
Exam answer pattern
For a 10-mark question: start with a definition, draw a labelled diagram, explain six to eight points under subheadings,
give examples/protocols, then write a one-line conclusion. For comparison questions, use tables. For security
questions, clearly distinguish encryption, hashing, authentication, integrity, and digital signatures.
2. Transport Layer
The Transport Layer is Layer 4 of the OSI model. Its primary purpose is process-to-process delivery: it delivers data not only
to the correct host but to the correct application process on that host. It uses port numbers and provides services such as
segmentation, reassembly, connection control, reliability, flow control, congestion control, and multiplexing.

TCP is connection-oriented. Before normal data transfer, it establishes a shared understanding of initial sequence numbers
using the three-way handshake. This prevents old duplicate segments from being treated as part of a new connection and
confirms that both directions are ready.

Connection established; data may now flow in both directions.
1. Client performs an active open and sends SYN with initial sequence number x.
2. Server responds with SYN+ACK: it acknowledges x+1 and announces its own initial sequence number y.
3. Client sends ACK for y+1. Both sides now know the other side is reachable and sequence spaces are synchronized.
Connection termination
TCP close is normally a four-segment exchange because each direction closes independently.

The Session Layer establishes, manages, synchronizes, and terminates dialogs/sessions between application processes. In
modern Internet implementations, many session functions are handled by application frameworks and protocols rather than a
separate universal Session-Layer protocol, but the OSI functions remain important for examination answers.

6. Email and Common Application Protocols
SMTP
SMTP (Simple Mail Transfer Protocol) is used to submit and relay email from a sender’s mail client/server to the recipient’s mail
server. It is a push/transfer protocol; it is not normally used by an end user to retrieve stored mail. For retrieval, POP3 or IMAP
is used.

MIME
MIME stands for Multipurpose Internet Mail Extensions. It extends the original email format so messages can carry non-ASCII
text, attachments, images, audio, video, documents, and multiple message parts. MIME does not itself deliver email; it
labels/encodes content for email transport.

7. Cryptography, Encryption and Decryption
Cryptography is the science and practice of protecting information through mathematical algorithms and keys. It protects data
stored on systems and data transmitted over networks. Cryptography supports confidentiality, integrity, authentication, and
non-repudiation when appropriate mechanisms are used.
Security goals
Goal
Meaning
Confidentiality
Only authorized parties can read information. Encryption supports this goal.
Integrity
Unauthorized alteration is detected. Hashes/MACs/digital signatures support this.
Authentication
Verifies identity or origin of a user/message/system.
Non-repudiation
A sender cannot credibly deny a signed action/message, subject to proper key control and legal context.
Symmetric-key encryption
Symmetric encryption uses the same shared secret key for encryption and decryption. It is fast and suitable for large amounts of
data. Its main challenge is secure key distribution: both parties must obtain and protect the same secret key. AES is a common
modern symmetric algorithm; DES is historically important but not considered secure for modern use.
Plaintext II Encrypt with shared secret key K III Ciphertext II Decrypt with same K III Plaintext
Asymmetric/public-key encryption
Asymmetric cryptography uses a mathematically related key pair: public key and private key. For confidentiality, a sender
encrypts using recipient’s public key and only recipient’s private key can decrypt. Asymmetric methods are slower than
symmetric encryption but solve key-distribution and digital-signature problems. RSA and elliptic-curve cryptography are
common examples.
Plaintext II Encrypt with receiver public key III Ciphertext II Decrypt with receiver private key III Plaintext
Hash functions
A cryptographic hash function converts input of arbitrary length into a fixed-length digest. Hashing is one-way: it is not
encryption and is not reversed by “decryption.” Hashes help verify integrity and are used with salts/slow password-hashing
schemes for password storage. Examples include SHA-256; weak legacy hashes should not be used for security.
Digital signatures
Digital signatures normally use asymmetric cryptography. Sender hashes the message and signs the hash using the sender’s
private key. Anyone can verify the signature using the sender’s public key. This supports authenticity, integrity, and
non-repudiation properties.
Cryptosystem components
Component
Meaning
Plaintext
Original readable information to be protected.
Encryption algorithm
Mathematical process that converts plaintext to ciphertext using key material.
Encryption key
Key used as input to encryption operation.
Ciphertext
Unreadable/protected output produced by encryption.
Decryption algorithm
Process that converts ciphertext back to plaintext using the correct key.
Decryption key
Key used to recover plaintext; same as encryption key in symmetric systems, different/private key in public-key confidentiality.
Key space
Set of all possible keys for a cryptosystem.

8. Routing Algorithms and Routing Tables
Routing is the process of selecting a path for packets across interconnected networks. Forwarding is the router’s local action of
sending a received packet to the appropriate next-hop interface according to its routing/forwarding table. The “best” route
generally means lowest cost according to a metric, not always simply the fewest hops.

9. Hamming Distance and Hamming Code
Hamming distance is the number of bit positions at which two equal-length binary strings differ. Example: distance between
`1011011` and `1001110` is 3 because three positions differ. The minimum Hamming distance of a code determines its
error-detection/correction capability.
Useful rule
A code with minimum distance dmin can detect up to dmin − 1 errors and can correct up to I(dmin − 1)/2I errors. Basic
Hamming codes have minimum distance 3 and can correct one-bit errors.
Hamming (7,4) code layout
Position: 1 2 3 4 5 6 7
Role: P1 P2 D1 P4 D2 D3 D4
Even parity groups:
P1 checks positions 1, 3, 5, 7
P2 checks positions 2, 3, 6, 7
P4 checks positions 4, 5, 6, 7
Received word example: 1011011 (even parity, positions numbered left to right)

Q1. Discuss the services offered by the Application Layer.
Asked: 2023–24, 2024–25, 2025–26
Answer
The Application Layer is the seventh and highest layer of the OSI model. It provides network services directly to end-user
applications. It acts as the interface through which application software uses the underlying network.
1. File transfer and management: Protocols such as FTP/SFTP enable upload, download, remote file access, directory listing,
and file management.
2. Email service: SMTP transfers email between clients/servers; POP3 or IMAP retrieves messages for users. MIME enables
attachments and multimedia mail content.
3. Web service: HTTP/HTTPS support communication between browsers and web servers for websites, web applications,
APIs, images, and multimedia resources.
4. Remote access: SSH enables secure terminal access to remote systems. Telnet is an older remote terminal protocol but is
insecure because it does not provide modern encryption.
5. Name service: DNS translates human-readable domain names into IP addresses, enabling users to access Internet services
by names rather than numeric addresses.
6. Directory service: LDAP-type services store and provide controlled access to users, groups, devices, and organisational
directory information.
7. Network management: SNMP and related tools support monitoring and management of network devices.
8. Messaging, collaboration and RPC: Application services support chat, presence, conferencing, remote procedure calls,
and distributed applications.
Conclusion: The Application Layer makes network resources useful to users by delivering services such as web access, email,
file transfer, remote login, name resolution, and collaboration.
Q2. Explain cryptography used for network security and privacy.
Asked: 2023–24, 2025–26
Answer
Cryptography is the use of mathematical algorithms and keys to protect information and communication from unauthorized
access or alteration. It is used in secure web browsing, online payments, VPNs, digital signatures, authentication systems, and
protected data storage.
Cryptography provides confidentiality so only authorised parties can read information; integrity so unauthorised changes are
detected; authentication so identities/origin can be verified; and non-repudiation so a validly signed sender cannot easily
deny an action/message.
Symmetric-key cryptography: the same secret key encrypts and decrypts data. It is fast and appropriate for bulk data
encryption. AES is a standard modern example. Its main issue is distributing the shared key securely.
Asymmetric-key cryptography: uses a public/private key pair. For confidentiality, sender encrypts using receiver’s public key
and receiver decrypts using private key. RSA and ECC are common examples. It is useful for key exchange and digital
signatures but usually slower than symmetric encryption.
Hash functions: create fixed-length one-way digests for integrity checking. Hashing is not encryption and cannot normally be
reversed. Hashes are used in integrity verification, signatures, and password-storage systems with secure salting/slow hashing.
Digital signature: sender signs a message hash with private key; verifier checks using public key. This supports authenticity
and integrity.
Conclusion: Modern secure systems commonly combine asymmetric cryptography for identity/key establishment, symmetric
encryption for bulk data, and hashes/signatures for integrity and authentication.

Q3. Explain encryption and decryption methods.
Asked: 2024–25
Answer
Encryption is the process of converting readable data, called plaintext, into unreadable protected data, called ciphertext, using
an algorithm and key. Decryption is the reverse process: it uses the correct key and algorithm to restore ciphertext to plaintext
for an authorised recipient.
Symmetric method: one shared secret key is used for both encryption and decryption. Diagram: Plaintext → Encrypt using key
K → Ciphertext → Decrypt using key K → Plaintext. AES is a common example. It is fast but needs secure key sharing.
Asymmetric method: uses a related public/private key pair. For confidentiality: Plaintext → Encrypt with receiver public key →
Ciphertext → Decrypt with receiver private key → Plaintext. RSA/ECC are examples. This solves public key distribution but is
slower for large data.
Hybrid method: Practical systems such as HTTPS normally use public-key methods to authenticate/exchange a temporary
symmetric session key, then symmetric encryption for actual bulk data because it is faster.
Conclusion: Encryption provides confidentiality during storage/transmission; decryption permits only the correct key holder to
read data.
Q4. Explain routing algorithms and write short notes on routing table.
Asked: 2024–25
Answer
Routing is path selection for packets across interconnected networks. A routing algorithm determines the best route according
to metric/cost such as hop count, delay, bandwidth, reliability, or administrative policy. Forwarding then sends a packet to the
selected next hop.
Static/non-adaptive routing: routes are manually configured and do not automatically change with failures or traffic. It is
simple and suitable for small stable networks but lacks adaptability.
Dynamic/adaptive routing: routers update routes based on network information. Distance-vector algorithms exchange
distance/cost information with neighbours; RIP is a classic example. Link-state algorithms build topology knowledge and
compute shortest paths; OSPF is an example. Path-vector routing is used between autonomous systems; BGP is the key
example.
Routing table: a router’s data structure containing destination network prefixes, prefix lengths/masks, next-hop addresses,
outgoing interfaces, metrics, and route source/type. The router uses longest-prefix matching to select the most specific suitable
route. A default route is used when no more specific entry matches.
Conclusion: Routing algorithms create/maintain route knowledge; routing tables are used for actual packet-forwarding
decisions.
Q5. Explain duties/functions of the Transport Layer.
Asked: 2016, 2017, 2022–23
Answer
The Transport Layer is Layer 4 of the OSI model and provides process-to-process delivery. It ensures that data reaches the
correct application process on the destination host, not only the correct machine.
1. Port addressing: source/destination ports identify applications and enable multiple applications to share one host/network
connection.
2. Segmentation and reassembly: large application messages are divided into segments and correctly reassembled at
destination.
3. Connection control: may establish/manage/release a connection-oriented service or send independent connectionless
datagrams.
4. Reliability: TCP uses sequence numbers, acknowledgements, checksums, timers and retransmission to recover from
losses/corruption and deliver bytes in order.
5. Flow control: prevents a fast sender from overwhelming a slower receiver using buffering/window mechanisms.

Q6. Explain the components of cryptography/cryptosystem.
Asked: 2022–23
Answer
A cryptosystem is a complete set of components used to protect information through encryption and decryption.
Plaintext: original readable information to be protected.
Encryption algorithm: mathematical procedure that takes plaintext and an encryption key and produces ciphertext.
Encryption key: secret/private/public key material used as input to encryption.
Ciphertext: scrambled output that should be unreadable without the appropriate decryption key.
Decryption algorithm: mathematical procedure that takes ciphertext and correct decryption key and restores plaintext.
Decryption key: key used to recover the plaintext. In symmetric cryptography it is the same shared secret key; in asymmetric
confidentiality it is usually the recipient’s private key.
Key space: set of all possible valid keys for a cryptographic scheme. Large key spaces make brute-force attacks harder.
Attacker/interceptor: unauthorised entity attempting to recover plaintext or keys. Secure cryptography assumes algorithms
may be publicly known; security should depend on protecting keys, not hiding the algorithm.
Q7. Explain Hamming distance. Received 7-bit Hamming codeword is 1011011 using even parity. Is it
correct? If not, locate error.
Asked: 2022–23
Answer
Hamming distance is the number of positions in which two equal-length binary strings differ. It is used to measure code
separation and determine error-detection/correction ability. Basic Hamming code adds parity bits at positions 1, 2, 4, and so on
to locate a single-bit error.
Assume the seven positions are numbered left to right. Received word: positions 1–7 = 1 0 1 1 0 1 1. With even parity, P1
checks 1,3,5,7 = 1,1,0,1, which has three 1s and fails. P2 checks 2,3,6,7 = 0,1,1,1, which has three 1s and fails. P4 checks
4,5,6,7 = 1,0,1,1, which has three 1s and fails.
Syndrome = P4P2P1 = 111I = 7. Therefore, bit position 7 is in error. Flip the seventh bit from 1 to 0. Corrected codeword =
1011010. Hence received codeword is wrong and has a single-bit error at position 7.
Always state the numbering convention in an exam because some texts number from the right; the method is unchanged.

Q9. What is SMTP? Explain its components with example.
Asked: 2019
Answer
SMTP, Simple Mail Transfer Protocol, is the standard Application-Layer protocol for submitting and relaying email. It transfers
outgoing messages from a user’s mail client to a submission server and between mail servers until the recipient domain’s
server accepts the message. It uses TCP for reliable transfer.
Components: MUA (Mail User Agent) is the user’s email client such as a webmail interface or mail app. MSA (Mail Submission
Agent) receives submitted outgoing mail. MTA (Mail Transfer Agent) relays mail between servers using SMTP and DNS MX
records. MDA (Mail Delivery Agent) places accepted mail in the recipient mailbox. The recipient then reads mail using IMAP or
POP3 through a MUA.
Example flow: Alice composes a message in MUA → submits it to her MSA → MTA queries DNS for the recipient domain’s
mail exchanger → sends SMTP message to recipient MTA → MDA stores it in recipient mailbox → Bob opens MUA and
retrieves/synchronizes mail using IMAP or POP3.
Conclusion: SMTP handles sending and relaying; IMAP/POP3 mainly handle user retrieval of received mail.
Q10. Write five Application-Layer protocols and explain each briefly.
Asked: 2018
Answer
SMTP: sends and relays electronic mail between mail clients/servers and mail servers.
HTTP/HTTPS: transfers web pages, APIs and web resources between browser/client and web server; HTTPS adds TLS

FTP: transfers files between hosts. Classic FTP uses a control connection and a separate data connection.
DNS: resolves domain names to IP addresses and provides other DNS records needed for Internet services.
Telnet/SSH: provide remote terminal access. Telnet is legacy and unencrypted; SSH is the secure modern alternative.
Other acceptable examples include POP3, IMAP, DHCP, SNMP, NTP, LDAP, and TFTP. In answers, always write the full form
plus one precise function.
Q11. Discuss difference between Presentation and Application Layer.
Asked in supplied Unit-V material
Answer
Presentation Layer: Layer 6. It handles data representation: translation between formats/character sets,
compression/decompression, encryption/decryption, and data syntax. It normally does not directly offer web/email/file services
to the user.
Application Layer: Layer 7. It provides network services directly to user applications, such as email, file transfer, web access,
DNS, remote login, and network management.
In short: Presentation Layer makes data understandable and secure across unlike systems; Application Layer makes network
services available to applications/users.

Answer
The Session Layer is Layer 5 of the OSI model. It establishes, manages, synchronizes, and terminates logical communication
sessions between applications.
Session establishment: creates a session and agrees communication parameters before an extended dialogue.
Session maintenance: manages the active session and coordinates the dialogue while communication continues.
Dialog control: manages who may send and when; supports half-duplex/full-duplex conversational coordination.
Synchronization: inserts checkpoints in a long data transfer or transaction. If failure occurs, processing can resume from the
latest checkpoint rather than beginning again.
Session termination: closes the session cleanly and releases resources.
Conclusion: These functions organize and recover long-running application conversations.

TCP vs UDP

SMTP sends/relays email; POP3/IMAP retrieves/accesses mailbox email.

Accuracy reminders
• The Application Layer is not the same thing as a user application; it provides services to applications.
• SMTP primarily sends/relays mail. POP3/IMAP are used to retrieve/access mailboxes.
• Hashing is not encryption. A secure hash is designed to be one-way.
• Encryption supports confidentiality; integrity/authentication/non-repudiation need appropriate hashes, MACs, signatures, and
key management.
• Routing chooses paths; forwarding sends packets using a route/forwarding table.
• A “best route” is lowest metric/policy cost, not necessarily fewest hops.
• TCP has orderly close using FIN/ACK; RST is normally an abrupt reset.
