A computer network is an interconnection of two or more autonomous computers and other
devices through wired or wireless communication links. It enables devices to exchange data,
communicate with each other, and share hardware, software, storage, and Internet services. A
network is formed using networking hardware such as network interface cards, switches,
routers, cables, wireless access points, and protocols.
1. Resource sharing: A network permits multiple users to share hardware resources such as
printers, scanners, storage devices, and Internet connections. This reduces unnecessary
duplication and cost.
2. File and data sharing: Users can access shared files, databases, documents, and
applications over the network. This makes collaborative work faster and more organized.
3. Communication: Networks support email, instant messaging, VoIP calls, video
conferencing, online classes, and collaboration tools.
4. Centralized data management: Important files and databases can be kept on central
servers. This improves control, reduces duplication, and makes data management easier.
5. Remote access: Authorized users can access files, applications, and systems from a remote
location through VPN, remote desktop, cloud platforms, or web applications.
6. Cost efficiency: Sharing one printer, one Internet link, common storage, and server-based
software is less expensive than providing separate resources to every computer.
7. Better security management: Administrators can apply authentication, authorization,
firewalls, antivirus policies, backups, and access restrictions centrally.
8. Reliability and backup: Centralized backup and redundant systems reduce the risk of
permanent data loss and improve availability.
9. Scalability: A network can be expanded by connecting more users, devices, switches, or
branches when required.

The effectiveness of a data-communication system depends on four fundamental
characteristics: delivery, accuracy, timeliness, and jitter.
1. Delivery: The system must deliver data to the correct destination. The information should
be received by the intended device or user and not by an unintended destination.
2. Accuracy: The system must deliver data accurately. Data altered during transmission
because of noise, interference, or faults becomes unusable unless errors are detected and
corrected.
3. Timeliness: The system must deliver data within an acceptable time. Late delivery may
have little value, especially in real-time applications such as live video, online lectures,
voice calls, and remote control systems.
4. Jitter: Jitter is the variation in the delay with which packets arrive at the receiver. Excessive
jitter produces poor-quality audio/video, pauses, distortion, or irregular playback.
Conclusion: A communication system is effective when it sends correct data to the correct
receiver at the right time with minimum variation in delay.

Parallel transmission is a method of data transmission in which multiple binary digits are sent
simultaneously over multiple separate communication lines. For example, if eight bits are
transmitted together, eight data lines are generally required along with additional control or
clock lines.
In parallel transmission, all bits of a character or data unit are sent at the same instant. This
can provide high speed over a short distance. It was traditionally used inside computers,
between closely placed hardware components, and in some older printer interfaces.
However, parallel transmission requires more wires and connectors, so installation cost is
high. It also suffers from timing skew over long distances because signals on different wires
may reach the receiver at slightly different times. Hence, parallel transmission is generally
used for short distances, while serial transmission is preferred for long-distance
communication.

Q11. How can errors be detected in networks? Define single-bit and multiple-bit
errors.
Answer
Single-bit error


--- PAGE 21 ---
A multiple-bit error occurs when two or more bits in the data unit are altered. The changed bits
do not need to be consecutive.
Sent:      10110101
Received:  10011100
Multiple-bit errors are harder to detect with simple parity. Therefore, stronger methods such as
CRC are used in practical networks.
Parity is the simplest error-detection method. An additional bit called a parity bit is added to
the data unit.
The parity bit is chosen so that the total number of 1s, including parity, becomes even.
The parity bit is chosen so that the total number of 1s, including parity, becomes odd.
Simple parity can detect an odd number of changed bits but may fail to detect an even number
of bit errors. It cannot identify the error position.
In checksum, data is divided into fixed-size words. The sender adds the words using one’s-
complement arithmetic and sends the complement of the sum as the checksum. The receiver
repeats the operation and checks the final result.
Checksum is widely used in Internet protocols, but CRC is generally more powerful for
detecting burst errors.
CRC is a widely used error-detection technique based on modulo-2 division. Modulo-2
arithmetic uses XOR operation instead of ordinary subtraction.

Suppose generator G has r + 1 bits.
1. Append r zeros to the dataword.
2. Divide the augmented dataword by G using XOR division.
3. Obtain an r-bit remainder.
4. Append the remainder to the original dataword.
5. Transmit the resulting codeword.
1. Receiver divides the complete received codeword by the same generator.
2. If remainder is all zeros, no detectable error is found and the frame is accepted.
3. If remainder is non-zero, an error is detected and the frame is rejected/retransmitted.
A zero CRC remainder does not mathematically guarantee that no error occurred. It means no
error detectable by the chosen generator was detected. In university answers, write: “The
frame is accepted when the remainder is zero; otherwise it is treated as erroneous.”

Asked: 2023–24
CRC detects errors by appending specially calculated redundant bits to a data unit before
transmission. The sender and receiver agree in advance on a generator bit pattern called the
divisor.
1. Let the generator have r + 1 bits.
2. The sender appends r zeros to the dataword.
3. The augmented dataword is divided by the generator using modulo-2 division, where XOR
is used instead of subtraction.
4. The remainder has r bits and is called the CRC.
5. The sender attaches this remainder to the original dataword to create the codeword.
6. The codeword is transmitted.
1. The receiver receives the complete codeword.
2. It divides the codeword by the same generator using modulo-2 division.
3. If the remainder is 000...0, the frame is accepted because no detectable error is found.
4. If the remainder is non-zero, the frame is considered damaged and is rejected or
retransmitted.
Sender:
Dataword + r zeros → XOR division by generator → CRC remainder
Dataword + CRC → Codeword transmitted
Receiver:
Received codeword → XOR division by same generator

1001 ⊕ 1011 = 0010
Bring down next bit → 0100

Bring down next bit → 1000

The last three bits are the CRC remainder:
