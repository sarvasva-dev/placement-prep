The Bisection Method repeatedly halves an interval [a,b] that contains a root. At every step
choose
c = (a+b)/2.
Then retain the half interval for which the endpoint function values have opposite signs.
1. Write the equation as f(x)=0.
2. Find a and b such that f(a)f(b)<0.
3. Calculate midpoint c=(a+b)/2.
4. Calculate f(c).
5. If f(c)=0, then c is the root.
6. If f(a)f(c)<0, put b=c; otherwise put a=c.
7. Repeat Steps 3–6 until the required decimal accuracy is achieved.
For a starting interval [a,b], after n bisections the interval length is
(b-a)/2^n.
The midpoint approximation has maximum error at most
(b-a)/2^(n+1).
To ensure error no more than ε, take
n ≥ log2((b-a)/ε) - 1.

Let [a_n,b_n] be the interval after the nth step. It always contains a root and
b_n-a_n=(b-a)/2^n → 0.
The lower endpoints form a bounded non-decreasing sequence and the upper endpoints form a
bounded non-increasing sequence. Both approach the same limit α. Since every interval
brackets a root and f is continuous, f(α)=0. Hence the method converges.

Regula-Falsi is a bracketing method. Instead of using the midpoint, it joins (a,f(a)) and
(b,f(b)) by a chord and uses the x-intercept of that chord as the next estimate.
For f(a)f(b)<0, the approximation is
x = (a f(b) - b f(a)) / (f(b)-f(a)).
Equivalent form:
x = a - f(a)(b-a)/(f(b)-f(a)).
1. Put the equation in the form f(x)=0.
2. Select a,b with f(a)f(b)<0.
3. Compute x=(a f(b)-b f(a))/(f(b)-f(a)).
4. Evaluate f(x).
5. If f(a)f(x)<0, replace b by x; otherwise replace a by x.
6. Repeat until successive estimates give the requested accuracy.
Solve x^2-9x+10=0 between 2 and 4.
f(2)=-4, f(4)=-10; therefore these two endpoints do not bracket a root. The PDF’s printed
question/expression appears OCR-corrupted because Regula-Falsi needs opposite signs. Always
check f(a)f(b)<0 before applying the method.
A valid illustration is f(x)=x^2-5, with [2,3]:
f(2)=-1, f(3)=4
x1=(2×4 - 3×(-1))/(4-(-1))=11/5=2.2
f(2.2)=-0.16, so the next bracket is [2.2,3].

Suppose x_n is an approximation to a root α of f(x)=0. Write
α=x_n+h.
By Taylor expansion around x_n:
f(x_n+h)=f(x_n)+h f'(x_n)+h^2 f''(x_n)/2!+...
Since f(α)=0, and neglecting second and higher powers of the small quantity h,
0 ≈ f(x_n)+h f'(x_n).
Therefore,
h ≈ -f(x_n)/f'(x_n)
and
x_(n+1)=x_n - f(x_n)/f'(x_n).
This is Newton–Raphson iteration.
1. Write f(x)=0 and calculate f'(x).
2. Choose an initial approximation x0 near the root.
3. Calculate x_(n+1)=x_n-f(x_n)/f'(x_n).
4. Continue until |x_(n+1)-x_n| is less than the desired tolerance.
5. Do not use an iterate where f'(x_n)=0 or very close to zero.

For a simple root α, if f'(α)≠0, f'' is continuous nearby, and the starting value is sufficiently
close, Newton–Raphson converges quadratically:
e_(n+1) ≈ [f''(α)/(2f'(α))] e_n^2, where e_n=x_n-α.
Meaning: once near the root, the approximate number of correct digits roughly doubles per
iteration. It can fail or move away if the initial guess is poor, the derivative is zero/small, or the
root is multiple.

For a polynomial f(x) with real coefficients:
The number of positive real roots is equal to the number of sign changes in f(x), or less
than it by an even integer.
The number of negative real roots is obtained by applying the same rule to f(-x).
1. Arrange the polynomial in descending powers of x.
2. Count sign changes in f(x) for possible positive roots.
3. Substitute -x for x to get f(-x).
4. Count sign changes in f(-x) for possible negative roots.
For f(x)=x^3-x^2-x-1, signs are +,-,-,-; there is one sign change. Thus it has exactly one
positive real root.
For negative roots:
f(-x)=-x^3-x^2+x-1, signs are -,-,+,-; there are two sign changes. Hence negative real roots
may be 2 or 0.

Define/Explain Descartes’ Rule of Signs.
Addition property: If A=B, then A+C=B+C.
Multiplication property: If A=B, then AC=BC.
Division property: If A=B and C≠0, then A/C=B/C.
Zero-product law: If XY=0, then X=0 or Y=0.
Quadratic formula: For ax^2+bx+c=0, a≠0,
x=(-b ± √(b^2-4ac))/(2a).
