# Placement Prep: AI-Powered Technical Interview & DSA Acceleration Engine 🎯

[![Live Demo](https://img.shields.io/badge/Live%20Demo-placement--prep-0070f3?style=for-the-badge&logo=vercel&logoColor=white)](https://placement-prep-topaz.vercel.app)
[![Tech](https://img.shields.io/badge/Stack-Vite%20%7C%20TypeScript%20%7C%20Gemini%20AI-blue?style=for-the-badge)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg?style=for-the-badge)](LICENSE)

A high-performance technical recruitment acceleration platform engineered to streamline software engineering interview preparation. Combines structured DSA roadmaps, company-wise coding problem archives (MAANG, Tier-1 MNCs, high-growth startups), interactive CS fundamentals cheat sheets, and dynamic AI mock interview simulations powered by **Google Gemini API**.

---

## ⚡ Key Highlights & Capabilities

- 🧩 **Comprehensive DSA Topic Roadmaps**: Arrays, Sliding Window, Trees, Graphs, Dynamic Programming, Backtracking, and Advanced Heuristics.
- 🤖 **Gemini AI Interview Simulator**: Interactive coding evaluations, time complexity analysis, and hint generation powered by `@google/genai`.
- 💻 **Core CS Fundamentals**: High-yield revision modules for Operating Systems (Processes, Threads, Semaphores), DBMS (Indexing, Normalization, ACID), Computer Networks (OSI/TCP, Sockets), and OOPs Design Patterns.
- 📊 **Target Company Archives**: Curated question frequencies categorized by hiring rounds (Amazon, Google, Microsoft, Adobe, Swiggy, Zomato).
- ⚡ **Ultra-Fast Edge Runtime**: Built with Vite and Bun for instantaneous page transitions and offline caching.

---

## 🛠️ Tech Stack

- **Runtime & Bundler**: Bun, Vite, Node.js
- **Frontend Framework**: TypeScript, Vanilla Modern DOM / Component Engine, Tailwind CSS
- **AI Integration**: Google Gemini 2.4 API (`@google/genai`)
- **Backend API**: Express.js microservice
- **Deployment**: Vercel Edge Network

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/sarvasva-dev/placement-prep.git
cd placement-prep

# Install dependencies (preferred: bun)
bun install

# Run the local development server
bun run dev
```
